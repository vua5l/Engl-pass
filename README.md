# English Passport · جواز الإنجليزية

موقع كورس إنجليزي شخصي لأسامة، من بداية A2 إلى C1 ثم ايلتس. يُنشر عبر GitHub Pages من فرع `main` على:
https://vua5l.github.io/Engl-pass/ (اسم المستودع في GitHub: Engl-pass)

الخطة الكاملة للكورس في مشروع Claude «دراسة الانجليزي» (ملف «خطة كورس الإنجليزية»).
هذا الملف دليل لكل من يعدّل الموقع: Claude أو Gemini أو يدويًا. اقرأه مع `CHANGELOG.md` قبل أي تعديل.

## قواعد العمل على المستودع

1. **محرّر واحد في كل مرة.** قبل البدء خذ أحدث نسخة من المستودع نفسه، لا نسخة قديمة محفوظة عندك. إن رُفعت نسخة قديمة محت تعديلات غيرك.
2. **كل تعديل أو إضافة يُوثَّق في `CHANGELOG.md`**: التاريخ، ومن عدّل، وماذا تغيّر، ولماذا، والملفات. هذه قاعدة صاحب الموقع، ليفهم كل محرّر ما فعله غيره.
3. **لا خطوة بناء.** الموقع يقرأ الملفات مباشرة، فعدّل الملف المعني وحده. لا تُعِد الموقع إلى ملف واحد كبير.
4. **بعد تعديل أي ملف ارفع رقم الإصدار** `?v=` لذلك الملف في `index.html` (أو لكل الملفات)، حتى لا يبقى الجوال على نسخة قديمة محفوظة.
5. **لا مفتاح في أي ملف.** مفاتيح GitHub وغيرها تبقى في متصفح الجوال وحده.
6. **فرع `progress` للتقدم وحده.** تكتبه المزامنة تلقائيًا، فلا تعدّله ولا تحذفه يدويًا. وتعديلات الموقع على `main`.
7. **شغّل الاختبار قبل النشر** إن أمكنك تشغيل Node (الطريقة في آخر الملف).

## بنية الملفات

```
index.html          الغلاف: يحمّل الملفات بالترتيب (البيانات، ثم الدروس، ثم المحرك)
app.css             الأنماط والألوان المعتمدة
app.js              المحرك: الشاشات، والمراحل الست، والحفظ، والمزامنة
content.js          بيانات الكورس العامة: الوحدات، وقوائم الدروس، والأفعال الشاذة،
                    ومختبر الأخطاء، وبطاقات كامبلي، واختبارات الوحدات والاختبارات القبلية
lessons/u0/l1.js    الأسبوع التأسيسي، الدرس 1 (إلى l5.js)
lessons/u1/l1.js    الوحدة 1، الدرس 1
tests/site.test.js  اختبار شامل في Chrome (يحاكي GitHub، ولا يلمس مستودعًا حقيقيًا)
README.md           هذا الدليل
CHANGELOG.md        سجل التغييرات
```

## إضافة درس جديد

1. أنشئ `lessons/u<الوحدة>/l<الرقم>.js` على هيئة درس موجود:
   `(function(){ LESSONS.u1l2 = { id: "u1l2", unit: 1, n: 2, mode: "reading", ... }; })();`
   والحقول المطلوبة: `recall`، `vocab`، `legalPhrase`، `vocabGaps`، `gCards`، `gA` إلى `gD`، و`reading` أو `listening`، و`writing`، و`quiz`.
2. أضف سطر `<script src="lessons/u1/l2.js?v=...">` في `index.html` بعد الدروس السابقة وقبل `app.js`.
3. في `content.js` اجعل الدرس `open: true` في قائمة وحدته (`unit1Lessons` مثلًا).
   ولوحدة جديدة أضف قائمة `unit2Lessons` بالشكل نفسه، فيدخلها ترتيب الكورس تلقائيًا.
   أما شاشة «الدروس» فتعرض اليوم الأسبوع التأسيسي والوحدة 1 فقط، وعرض الوحدة 2 يحتاج تعديلًا صغيرًا في `vLessons` داخل `app.js`.
4. **درس الاستماع**: المقطع تسجيل بشري حقيقي من مصدر معتمد (LearnEnglish من المجلس الثقافي البريطاني، أو BBC، أو ELLLO).
   يُختار المقطع أولًا ثم يُبنى الدرس حوله، و`listening.url` يفتح صفحة المقطع نفسه لا فهرسًا عامًا.
   ولا يُنسخ نص المقطع إلى الموقع لأنه محفوظ الحقوق: لا تضع `transcriptParas`، فتفتح المرحلة الثالثة النص في صفحة المصدر.
   وتُكتب الأسئلة وشروحها بكلمات كاتبها لا بجمل المقطع، ويُذكر في الشرح موضع الجواب من المقطع (في أوله أو وسطه أو آخره).
   والحقول على هيئة `u0l2` و`u0l4`: `title`، و`url`، و`sourceTag` (شارة المصدر)، و`sourceMeta` و`speakers` (سطر المصدر في المرحلة الثالثة)،
   و`targetSeconds` (طول المقطع تقريبًا)، و`predict` (سؤال الفكرة العامة، وشرحه في `revealEn` و`reveal`)، و`insight`، و`questions`.
   ولا يُكتب «تسجيل بشري موثّق» لحوار مؤلَّف.
5. سجّل الإضافة في `CHANGELOG.md`.

## الحفظ والمزامنة

- يُحفظ التقدم في الجهاز أولًا:
  - `ep4.course`: حالة الكورس كله: دفتر الأخطاء ومختبرها، ومراجعة الأفعال الشاذة، والوضع المختصر، ودقائق التدريب، وسجل كامبلي، واختبارات الوحدات، ودرس اليوم.
  - `ep4.lesson.<id>`: حالة درس واحد: إجاباته ومراحله وكتابته وبطاقاته.
  - `ep4.sync` (المفتاح) و`ep4.syncmeta`: لا يُرفعان أبدًا، ولا يدخلان النسخة الاحتياطية.
- دفتر الأخطاء للكورس كله، ويعود السؤال بعد يوم، ثم 3 أيام، ثم أسبوع، ثم شهر، ويخرج بعدها.
- المزامنة اختيارية، وإعدادها في نافذة الترس. ترفع إلى فرع `progress` ملفًا لكل حالة:
  `progress/course.json` و`progress/lesson-<id>.json`، ولا يُرفع إلا ما تغيّر.
  ويكون الرفع عند إنهاء أي مرحلة أو جلسة، وعند مغادرة الموقع، واحتياطًا إن بقي تغيير لم يُرفع ثلاث دقائق.
  وعند فتح الموقع يُسحب ما تغيّر في السحابة دون إعادة تحميل.
- المفتاح المطلوب: Fine-grained personal access token، يشمل المستودع `engl-pass` وحده، بصلاحية Contents: Read and write.
  وهو مستقل عن مفتاح مستودع مواد الكلية.

## نواقص معروفة

- تصحيح الكتابة خارج claude.ai فحص آلي محدود، وتسميته «تصحيح المعلم» ودرجته مضللتان. ومرحلته القادمة: مفتاح Gemini، وطريق نسخ ولصق مع Claude.
- نص «نسخ للمحادثة» في الكتابة يقول «الدرس الأول»، وشرح ألوان نموذج الكتابة خاص بالمضارع البسيط والمستمر ويظهر في كل الدروس.
- شاشة «الكلمات» تعرض كلمات الدرس الحالي وحده.

## تشغيل الاختبار

من جذر المستودع، في بيئة فيها Node وPlaywright وChrome:

```
NODE_PATH=/opt/npm-tools/node_modules node tests/site.test.js
```

ويمكن تحديد مسار Chrome بالمتغير `CHROME_PATH`. يشغّل الاختبار خادمًا محليًا، ويمر بالدروس الستة كاملة، ويحاكي GitHub في الذاكرة.
